# mismatch-scripts
Sample sizes of the MISMATCH project were determined using simulation-based power analyses in R, reflecting the within-participant structure of WP1 and WP2.
For WP1, simulations replicated the six-participant “blocks” (2 NT, 2 AU, 2 SZ), the nine-dyad network, and incorporated participant and dyad random effects. 
For WP2, simulations replicated a simpler four-participant "block" (2 NT and 2 AU) and incorporated participant and dyad random effects.
